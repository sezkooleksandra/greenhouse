Система обліку подій (Scala 3, sbt, ScalaTest). Стан бака обчислюється згортанням (`foldLeft`)
послідовності подій; помилки повертаються як `Either[DomainError, TankState]`.

Події: `Refill`, `Irrigate`, `AddFertilizer`, `DrainSludge`.
Розрахунки: поточний рівень, сумарна витрата поливу, топ-2 за інтенсивністю, заборона поливу нижче мінімального датчика.

Запуск тестів: `sbt test`
